# 知境 V0.1 实施计划

1. 工程与配置：Vue 3 + TypeScript、Spring Boot 3.5、MySQL Compose、环境变量与开发规范。
2. 数据模型：Flyway 建表，科目与七章知识目录，三个明确标注待审核的演示故事；故事与知识多对多。
3. API：目录查询、剧情查询、服务端判分、完整解析与知识卡；提交前不返回答案和后续剧情。
4. 移动端：统一蓝紫设计，首页、知识地图、逐步剧情、全部解析、翻转卡片和我的学习。
5. 学习记录：独立本地存储适配器，完成、收藏、复习、最近访问与持久化异常反馈。
6. 验证与文档：业务单测、API 泄露测试、MySQL 集成测试、前端状态测试、构建与真实流程检查。

## 验证边界

- 本机初始环境：Java 24、Node 24、Maven 3.9.6；代码编译目标 Java 21。
- Docker CLI 可用，但初始 Docker 引擎未运行；尝试启动后再验证 MySQL，若仍不可用则明确记录。
- 不以模拟 API 或 H2 替代真实 MySQL 验收。
- 当前先实现单问题演示故事：场景 → 选择 → 反馈与全部解析 → 知识总结 → 完成与解锁卡片。
