# 知境设计系统

技能检索推荐柔和卡片与故事引导。以下按用户明确的蓝紫配色和成人考研受众调整，覆盖检索默认的青色与儿童字体建议。

- 背景 #f6f5fc，主要文字 #302c49，次要文字 #68617d，主色 #6854c4，浅紫表面 #efebfc，白色卡片。
- 系统中文字体，不加载外部字体；正文 14–15px，移动端标题 26–37px，足够行高，桌面长剧情限制阅读宽度。
- 卡片圆角 20–28px，按钮圆角 16px；间距以 4/8px 节奏为基础。
- 本地 SVG 书屋、咖啡馆和小站插画，无外部图片依赖。
- 四个底部导航：发现、知识地图、知识卡片、我的学习。手机使用底部安全区，桌面使用悬浮导航。
- 题目使用原生 radio + fieldset/legend；主要按钮至少 44px 可点击区域，提供键盘焦点。
- 状态同时用文字标记；提供加载、失败与重试、空卡片集、内容未开放等独立状态。
- 页面淡入 160ms、按钮反馈 200ms；支持 prefers-reduced-motion，卡片翻转保留按钮语义。
- 未审核资源明确演示标记，无虚构用户、排行榜、学习时长或掌握率。
- 目标宽度 320–430px，同时兼容桌面；浏览器自动验证 320、390、1440px。只提供明亮主题。
