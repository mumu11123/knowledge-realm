# 知境（Knowledge Realm）

> 在故事里，理解知识。

面向计算机考研 408 的移动端互动式学习平台，通过生活场景、互动剧情、答题解析和知识卡片帮助理解知识。

## 项目状态

仓库已初始化，功能开发尚未开始。完整需求见 [项目需求](docs/PROJECT_REQUIREMENTS.md)。

## 计划技术栈

- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、Tailwind CSS、Axios
- 后端：Java 21、Spring Boot 3.5.x、Maven、MyBatis
- 数据库：MySQL 8、Flyway
- 测试：JUnit 5、Spring Boot Test，以及前端单元测试

## V0.1 目标

- 408 科目入口与数据结构知识地图
- 约三个完整演示故事：顺序表与单链表、栈、队列
- 服务端判分、不同剧情反馈和全部选项解析
- 可收藏和复习的知识卡片
- 浏览器本地游客学习记录

采用前后端分离的单仓库结构。第一阶段不接入大模型，不实现注册登录。

## 内容原则

故事与知识解耦；演示内容明确标注；未审核内容不作为正式教学内容发布。
